# 阶段 0-3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可在 Windows 上运行的阶段 0-3 代码和实验脚本。

**Architecture:** 框架无关的 `int8kv` 包，加薄的 `experiments/` 命令行脚本；实验结果写入 `results/` 并提交回仓库。

**Tech Stack:** Python 3.9+（Windows 用 3.11）、PyTorch、transformers==4.57.6、pytest、matplotlib。

**Spec:** docs/superpowers/specs/2026-11-07-int8-kv-cache-design.md

## Global Constraints
- 张量布局 `[batch, heads, tokens, head_dim]`。
- 量化范围 `[-127, 127]`，scale = absmax / 127。
- transformers 固定为 4.57.6。
- 文件读写一律 UTF-8，路径用 pathlib，保证 Windows 可运行。

## Review Focus
- 全零 token：不能产生 NaN。
- 没有 GPU 或 CUDA 版 PyTorch 没装好：Windows 脚本要明确报错。
- 模型输入带 attention mask：INT8 路径不能忽略 mask。
- Cache 被裁剪或重复使用：scale 必须和 token 对齐。
- Windows 控制台编码：脚本输出和结果文件不能因中文或编码崩溃。
